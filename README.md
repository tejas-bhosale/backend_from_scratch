# backend-from-scratch

Nine layers of the backend stack, built from scratch in Python.
Full plan: [docs/nine-layers.md](docs/nine-layers.md) · Schedule: [docs/schedule.md](docs/schedule.md)

## The weekly loop
- **Sun 15 min** — write next week's question into the layer's NOTES.md
- **Tue 60 min** — cold attempt, no reading. Log where you got stuck.
- **Thu 60 min** — read only enough to answer what you logged
- **Sat/Sun 3–4 h** — build. Last 30 min: take the measurement.
- **Sun 45 min** — write the mechanism in your own words, commit

A week is done when it produced **a commit, a number, and a paragraph.**
